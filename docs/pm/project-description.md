# Описание проекта

## 1. Описание проекта

bandcamp-parser — одностраничное веб-приложение, которое собирает структурированные данные с HTML-страниц релизов Bandcamp (альбомы и треки) и сохраняет их в виде отчётов. Пользователь вводит URL, система парсит страницу, показывает карточку релиза и список ошибок разметки, а также хранит историю отчётов.

## 2. Задачи

- Реализовать парсер HTML-страниц Bandcamp без скачивания аудио.
- Предоставить API для парсинга, просмотра и удаления отчётов.
- Сделать одностраничный интерфейс на Svelte.
- Обеспечить тестирование бэкенда и фронтенда в CI.
- Оставить точку расширения для будущей загрузки аудио.

## 3. Цель

Дать пользователю быстрый способ получить основные данные релиза (название, артист, треки, цена, обложка, тексты, описание, комментарии) и сохранить результат для последующего просмотра.

## 4. Алгоритм работы

1. Пользователь вводит URL релиза Bandcamp.
2. Фронтенд отправляет `POST /api/parse`.
3. Бэкенд скачивает HTML и вызывает `parse_release`.
4. Парсер извлекает `data-tralbum`, мета-теги и комментарии, формирует словарь с полями и списком `errors`.
5. Результат сохраняется в SQLite и возвращается клиенту.
6. Пользователь видит карточку и может открыть или удалить сохранённый отчёт.

## 5. Архитектура

Кратко: SPA (Svelte) раздаётся nginx, nginx проксирует `/api` к Flask, Flask парсит HTML и пишет отчёты в SQLite. Подробнее — в [architecture.md](architecture.md).

## 6. Тестирование

- Бэкенд: 14 тестов pytest, покрытие 88%.
- Фронтенд: 3 теста vitest.
- CI: GitHub Actions через docker compose.
Подробности — в `docs/qa/`.

## 7. Заключение

Проект реализует требуемый функционал парсинга и хранения отчётов, покрыт тестами и готов к расширению загрузкой аудио через `AudioDownloader`.
