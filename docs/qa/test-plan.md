# Тест-план

## Область

В скоупе:

- Парсер бэкенда (`parse_release`) для страниц альбомов и треков.
- REST API: parse, список отчётов, получение отчёта, удаление, health, Swagger.
- Одностраничное фронтенд-приложение: форма, карточка релиза, история, удаление.
- Выполнение CI в Docker Compose.

Вне скоупа:

- Реальные сетевые запросы к Bandcamp в юнит-тестах (используются HTML-фикстуры).
- Загрузка аудио (не реализована).
- E2E-автоматизация браузера (пока нет; кандидат для следующей итерации).

## Типы тестов

- Юнит: pytest (бэкенд), vitest (фронтенд).
- Интеграционные: API-тесты через тестовый клиент Flask против временной SQLite.
- Дымовые: `docker compose up` + curl health и фронтенда.

## Критерии входа/выхода

- Вход: код компилируется, зависимости устанавливаются, фикстуры на месте.
- Выход: все тесты зелёные в CI, нет открытых P1-багов.

## Целевое покрытие

- Бэкенд: >= 80% (сейчас 88%).
- Фронтенд: критичные пути (parse, история, удаление).
